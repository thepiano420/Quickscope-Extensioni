# Quickscope-Extension
 Chrome extension that automatically detects and highlights manipulative dark patterns on websites, classifying them by severity (Low to Critical) using pattern-matching algorithms across 10+ dark pattern categories.

 This system works by examining every webpage the user visits and checking it for possible dark patterns. When a webpage loads, the extension reads the HTML, CSS, text, and interface elements. The content script is then injected into the page, which allows the system to scan the structure of the DOM and all visible elements. Before detection begins, the preprocessing module cleans the text, filters unnecessary nodes, and prepares everything for analysis.
The detection engine has two main components. The text rule checker looks for manipulative language such as urgency phrases or confirm shaming. The UI structure checker focuses on design based patterns, such as hidden fees in small print, pre checked boxes, or visually biased buttons. After collecting all rule matches, the decision module evaluates the findings and determines whether the element should be classified as a dark pattern.

When the content script starts running, it removes any previous highlights and then applies each detector one by one. Some detectors look for text matches using regular expressions, such as phrases like limited time or only a few left. Others check the design of elements, such as when an accept button is visually larger or more emphasized than the reject option. Some detectors analyze checkboxes to see if they are pre selected while using keywords that imply consent for marketing, tracking, or data sharing. Others look for very small or low contrast text that includes hidden fees, taxes, or renewal terms. The script also checks for disguised ads by examining element attributes, classes, and data tags that often hide promotional content.

Whenever the script identifies something suspicious, it highlights the element directly on the webpage. The highlight uses colored outlines and background shades to indicate severity levels ranging from low to critical. Each highlighted element also receives a tooltip that appears when the user hovers over it. The tooltip explains the category of the dark pattern and the reason why the element may be manipulative. The content script saves detection results locally using chrome.storage so that the popup interface can display them.

The extension also tracks global statistics such as total detections, detections by category, and detections by severity. It associates these with each website visited and stores a short history of scans. This tracking happens entirely within the browser so the user does not need to depend on an external server. The system remains fast and private because everything is processed locally on the client side.
